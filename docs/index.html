HTML Foundamentals

What is HTML? - HTML stands for HyperText Markup Language

HTML document structure - An HTML document is made up of a series of elements that define the structure and content of the page.

Term: Definition

<!DOCTYPE html> - Declares that the document is an HTML5 document.

<html> - The root element of an HTML document.

<head> - Contains meta information about the document.

<body> - Contains the visible content of the HTML document.

HTML elements - The building blocks of an HTML document.

HTML Tags - The syntax used to create HTML elements.

Opening and closing tags - The syntax used to define the start and end of an HTML element.

Nested elements - Elements that are contained within other elements.

HTML attributes - Additional information about an HTML element.

Comments - Text within the HTML code that is not displayed in the browser.

Whitespace - The space between HTML elements.

Case Sensitivity - HTML tags are not case-sensitive.

Global attributes - Attributes that can be used on any HTML element.
